# Design system

Export HQ uses a calm, precise B2B visual language. Ink, warm paper, muted slate, and restrained green/amber/red states keep operational data dominant. Typography prioritizes compact readability and tabular numbers.

Components make owner, state, next action, and due date visible. Empty states explain why the module matters and offer one meaningful action. Dense tables become stacked records on narrow screens rather than horizontally compressed spreadsheets.

Accessibility baseline: semantic landmarks, labelled controls, visible focus, WCAG AA contrast, keyboard operation, reduced-motion support, and status communicated with text as well as color.
