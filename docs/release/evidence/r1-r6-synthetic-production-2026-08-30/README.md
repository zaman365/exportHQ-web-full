## Deliberately inactive production capabilities

`EXPORTHQ_ACTIVATION_GATES_PASSED` is empty. Cloudflare retains the existing
Clerk application keys and platform-admin allowlist, but the application Worker
has no `DATABASE_URL`, `CLERK_WEBHOOK_SECRET`, Hyperdrive binding, or R2 binding.
Accordingly, persistent customer workspaces, webhook projection, and evidence
uploads are not represented as available. No synthetic fixture can cross into a
tenant-authoritative surface.

Production Neon/Hyperdrive, Clerk webhook delivery, R2, recovery evidence, and
independent approvals remain separate activation gates. This deployment does
not waive or fabricate them.
